Photos of Ramon, the real dog the game is about. .png, .gif, .jpg and .jpeg
are all accepted (unlike the screenshots folder, which ignores .jpg).

Filenames are shown as the image alt text and sorted alphabetically, so the
numbering is the display order:
  ramon-01.png, ramon-02.png   the two photos carrying the game logo
  ramon-03.jpeg onwards        everything else

An optional ramon.zip here adds a "download all" button.
