Steam capsule art goes here. .png, .gif, .jpg and .jpeg are all accepted
(unlike the screenshots folder, which ignores .jpg).

Filenames are shown as the image alt text and sorted alphabetically, so name
them usefully, e.g.:
  capsule-header-460x215.png
  capsule-main-616x353.png
  capsule-vertical-374x448.png
  capsule-library-600x900.png

An optional capsules.zip here adds a "download all" button.
