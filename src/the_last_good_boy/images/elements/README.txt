The individual art assets the capsules are built from: character art, logo
lettering, backgrounds, and so on.

Images (.png .gif .jpg .jpeg .svg .webp) are shown as a clickable gallery.
Anything else (.psd, .ai, .zip, fonts) is listed as a download link instead, so
source files still reach press rather than being ignored.

Sorted alphabetically, so name them in the order you want them shown.
An optional elements.zip here adds a "download all" button.
